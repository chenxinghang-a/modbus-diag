# 原理图绘制工作表

> 本文件由 `hardware/tools/gen_schedule.py` 从 `netlist.json` 自动生成，请勿手改。
> 打开 KiCad → 新建工程 → 按下面的顺序放符号 → 照「同网其它成员」连线。

元件 **49** 个，网络 **37** 条。

## 1. 绘制顺序

| 步骤 | 内容 |
|---|---|
| 1 | 主控：先放 ESP32-S3-WROOM-1，它是所有网络的枢纽 |
| 2 | 电源：AMS1117 + 输入输出电容（C1/C2/C3/C4/C11） |
| 3 | 下载：CH340C + USB 座 J1 + ESD U5 + CC 下拉 R1/R2 |
| 4 | RS-485：MAX3485 + 端接 R6/JP1 + 偏置 R14/R15 + TVS D4/D5 |
| 5 | 显示：14P 排座，注意 VCC 与 T_CLK/T_DIN |
| 6 | 按键与复位/BOOT：4 个功能键 + BOOT + RST |
| 7 | 剩余：R5/R10/C10、LED D1/D2/R8/R9、背光 Q1/R11 |
| 8 | 波形：R3/R4 分压 + D6 钳位 |
