# 原型机搭建指南（不用等 PCB）

> 目标：**一天之内**拿到一台能拿在手里的样机，把 `docs/上板验证清单.md` 跑完，
> 同时给论文 6.x 提供真实数据。原理图与 PCB 照常画，但不必阻塞在这条路上。

## 1. 材料清单

| 物料 | 规格 | 数量 | 备注 |
|---|---|---|---|
| ESP32-S3 开发板 | DevKitC-1 / 任意带 USB 的 S3 板 | 1 | 需 8MB Flash 以上（固件约 900KB） |
| ILI9341 显示屏 | 2.4"/2.8" SPI 接口 | 1 | **带 XPT2046 触控的也可以**，固件不用触控 |
| TTL 转 RS-485 模块 | MAX3485/SP3485 等，带 DE/RE 方向控制 | 1 | 要能控方向脚，纯自动方向的会丢首字节 |
| 轻触按键 | 6×6mm | 4 | UP / DOWN / OK / BACK |
| 电位器或分压 | 10k | 1 | 给 ADC 一个可变电压，验证波形页 |
| 杜邦线 + 面包板 | — | 1 套 | — |
| USB 线 | 数据线（非充电线） | 1 | |

成本约 150~250 元，淘宝/立创商城均可。

## 2. 接线表

固件引脚定义在 `components/common_config/app_config.h`。**如果某脚在你的板子上不好接，
改这个文件即可**（改完必须重新烧录）。

| 功能 | ESP32-S3 GPIO | 接到 |
|---|---|---|
| TFT SCK | 12 | 屏模块 SCK/CLK |
| TFT MOSI | 11 | 屏模块 MOSI/SDI |
| TFT CS | 10 | 屏模块 CS |
| TFT DC/RS | 9 | 屏模块 DC/RS |
| TFT RST | 8 | 屏模块 RES/RESET |
| TFT BL | 7 | 屏模块 BL/LED（背光） |
| RS-485 DI（TX） | 17 | 485 模块 DI/RO 侧的 TX |
| RS-485 RO（RX） | 18 | 485 模块 RO |
| RS-485 DE/RE | 4 | 485 模块 DE 与 RE（短接在一起） |
| 按键 UP | 1 | 按键一端，另一端接 GND |
| 按键 DOWN | 2 | 同上 |
| 按键 OK | 42 | 同上 |
| 按键 BACK | 41 | 同上 |
| ADC 波形输入 | 5 | 电位器中点（量 0~3.3V） |
| 状态灯 | 48 | LED 阳极（串 220Ω 到 GND） |
| 电源 | 3V3 / GND | 屏与 485 模块的 3.3V / GND |

**按键接法**：一端接 GPIO，一端接 GND。固件已启用内部上拉，不需要外部电阻。

**485 模块注意**：DE 和 RE 要短接后一起接到 GPIO4；A/B 接被测总线的 A/B（注意别接反，接反了会收不到任何报文）。

## 3. 不要占用的脚

| GPIO | 原因 |
|---|---|
| 19 / 20 | USB D- / D+（USB 串口与 USB-JTAG） |
| 26 ~ 32 | SPI Flash（WROOM-1 模组内部占用） |
| 33 ~ 37 | PSRAM（N8R8 版本为 8 线/8 线，内部占用） |
| 43 / 44 | UART0（日志输出，占用后看不到串口日志） |
| 39 ~ 42 | 硬件 JTAG（MTCK/MTMS/MTDI/MTDO）。本设计用 41/42 做按键，**意味着不能同时接外部 JTAG 调试器**；用 USB-JTAG 不受影响 |

`hardware/tools/check_hardware.py` 已内置 GPIO 冲突检测：改动引脚后跑一次，
两个功能抢同一个脚会直接报 FAIL。

## 4. 烧录

```bash
# Windows，在仓库根目录
export IDF_PATH="C:/Users/cxx/esp-idf"
export PATH="/c/Users/cxx/.espressif/tools/xtensa-esp-elf/esp-14.2.0_20241119/xtensa-esp-elf/bin:$PATH"
idf.py -p COMx flash monitor
```

`COMx` 换成设备管理器里看到的端口。首次烧录用 USB 口（GPIO19/20 那路）。

## 5. 上电后先看什么

按顺序，任一步不对就停下来查，不要继续往下走：

1. **串口日志**：应看到 `all 8 pages registered`、`RS-485 restored: ...`。
   看不到日志 = 没烧上或选错串口，先解决这个。
2. **屏幕**：应显示主菜单（6 个条目 + 底部按键提示）。白屏 = 背光或接线问题；
   花屏/乱码 = SPI 速率或接线过长。
3. **按键**：上下移动菜单高亮，OK 进入，BACK 返回。
4. **波形页**：拧电位器，波形应随之变化，`Vpp` 数值跟着变。
5. **RTU 扫描**：接一台 Modbus 从站（或用 PC 上的 `sim/modbus_sim.py` 经 485 模块回环），
   扫描应能找到设备。

## 6. 常见现象与排查

| 现象 | 最可能的原因 |
|---|---|
| 白屏但有背光 | MOSI/SCK 没接好，或 CS/DC 接反 |
| 有背光但全黑 | BL 脚电平不对，或 RST 一直拉低 |
| 扫描不到任何设备 | ① A/B 接反 ② DE/RE 没短接 ③ 波特率/帧格式不匹配（试设置页的 8E1） |
| 能收不能发 | DE 方向脚没接或接反 |
| 按键无反应 | 接成了接 VCC 而不是 GND（内部上下拉方向反了） |
| 波形是一条直线 | 电位器没接到 GPIO5，或接到了已占用脚 |
